📊 Database Configuration

PostgreSQL (Recommended for Production)

Set your DATABASE_URL in the .env file:

DATABASE_URL=postgresql://username:password@host:port/database_name

Example providers:

Render Supabase Railway Heroku AWS RDS Google Cloud SQL

MySQL (Alternative)

Set these variables in .env:

USE_MYSQL=true DB_HOST=localhost DB_PORT=3306 DB_USER=root DB_PASSWORD=your-password DB_NAME=disaster_db

SQLite (Development Only)

No configuration needed. Used automatically if DATABASE_URL and USE_MYSQL are not set.

Database file: instance/disaster_app.db

🔑 Environment Variables (.env file)

SECRET_KEY=your-secret-key-here JWT_SECRET_KEY=your-jwt-secret-key-here DATABASE_URL=postgresql://username:password@host:port/database_name FLASK_ENV=development

🔌 API Endpoints

Authentication

POST /auth/register

Register a new user

Body: { "name": "John Doe", "email": "john@example.com", "password": "password123", "role": "student" // student, faculty, or admin }
POST /auth/login

Login and get JWT token

Body: { "email": "john@example.com", "password": "password123" } Response: { "access_token": "eyJ0eXAi...", "user": { "id": 1, "name": "John Doe", "role": "student" } }

Safe Zones

GET /safe_zones

Get all safe zones (55+ locations across India)

Regions covered: All Indian states and Union Territories

GET /safe_zones/:id

Get specific safe zone by ID

POST /safe_zones/:id/mark

Mark a safe zone as visited (student feature)

🔒 Requires Authentication
DELETE /safe_zones/:id/mark

Unmark a safe zone

🔒 Requires Authentication
GET /safe_zones/marked

Get user's marked safe zones

🔒 Requires Authentication

Disaster Modules

GET /modules

Get all educational modules

POST /modules/:id/attempt

Submit quiz answers and get score

Body: { "answers": [0, 2, 1, 3, ...] // Array of selected option indices } Response: { "score": 85.5, // Percentage "correct": 13, "total": 15, "points_earned": 128 }
🔒 Requires Authentication

Emergency Contacts

GET /emergency-contacts

Get all emergency contacts

Includes: Ambulance (102), Police (100), Fire (101), NDRF, Red Cross

Messages

GET /messages

Get user's messages

🔒 Requires Authentication
POST /messages

Send a message

Body: { "receiver_id": 2, "content": "Message text" }
🔒 Requires Authentication

🔒 Admin Only

🗄️ Database Schema

Table Key Columns Description
users id, name, email, password, role User accounts (student, faculty, admin)
safe_zones id, name, latitude, longitude, description 55+ safe zones across all Indian states
user_safe_zones user_id, zone_id, marked_at Track which zones students have visited
modules id, title, content, points, quiz_questions, image_url Educational disaster modules with quizzes
user_achievements user_id, module_id, score, points_earned Student quiz scores and points
emergency_contacts id, name, organization, phone, category Emergency service contacts
disasters id, name, description, severity Disaster type information
messages sender_id, receiver_id, content, timestamp User messaging system
drills id, name, scheduled_at, disaster_type Disaster preparedness drills
alerts id, message, severity, active Emergency alerts

🚀 Setup Instructions

Backend Setup

# Install dependencies pip install -r requirements.txt # Create .env file and configure database cp .env.example .env # Edit .env with your DATABASE_URL # Run the application python app.py # Server will start on http://127.0.0.1:5000

Frontend Setup

# Navigate to frontend directory cd frontend # Install dependencies npm install # Start development server npm start # Application will open at http://localhost:3000

Database Migration

# The application automatically creates tables on first run # All tables will be created in your configured database # 55+ safe zones will be seeded across all Indian states # Emergency contacts and sample module will be added
